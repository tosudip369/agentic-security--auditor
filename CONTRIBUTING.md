# Contributing to Agentic Security Auditor

Welcome aboard! We are thrilled you want to contribute to our autonomous security agent.

## The Core Philosophy
All contributions MUST align with **The 5-Step Engineering Algorithm**:
1. Question requirements
2. Delete unnecessary parts
3. Simplify and optimize
4. Accelerate cycle time
5. Automate

## Architecture Rules & AI Tuning
- **Hyperparameters:** Extract model config (like temperature, max tokens, API thresholds) into explicit variables.
- **Captain Protocol:** The AI prompts and console outputs must remain professional, polite, and address the user as "Captain".
- **Zero Latency:** Ensure scanning logic is as fast as possible.

## Getting Started
1. Fork the repository.
2. Run python -m pip install -r requirements.txt.
3. Create a feature branch: git checkout -b feature/your-feature.

## Submitting a PR
- Ensure your local scanner passes without false positives.
- Fill out the PR template completely.
